# REACT submission package — 10 November 2026

This release is the manuscript-aligned supplementary code and data package for
*Beyond Composite Rankings: A Probabilistic Multi-Domain Assessment of Regional Energy Resilience*
(Energy Strategy Reviews).

- Uses the 1 October 2025 archived MaStR battery-energy panel for all 16 states.
- Includes scripts for the complete main analysis, R1/R3 checks, reproducibility outputs,
  figures, climate sensitivity, support-layer comparisons, and manuscript tables.
- The principal Energy System indicators are demand-relative; PRESS residuals
  define the relative-weakness diagnostic.
- Main identified cases: Baseline 2; National Pool 4; Adjacency Flow 4.
- M0 fixed-input diagnosis identifies 13 states; M1 weight uncertainty retains 4.
- All 24 Python modules in the submitted package pass compilation.

The previous repository version is preserved in the GitHub branch
`archive-pre-final-2026-11-10`; the default branch contains this current package.
